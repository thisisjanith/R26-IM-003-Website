# Narrative-Based AR for Early STEAM Education (R26-IM-003)

Welcome to the project showcase website for **R26-IM-003: Narrative-Based Augmented Reality for Early STEAM Education**. This platform presents our final year research, a bilingual, offline AR storybook framework designed for Sri Lankan Grade 4–5 students covering Basic Measurement, Life Science, Physical Science, and Number Concepts.

## 🚀 Features

- **Four Dedicated Components**: 
  - *Measurement*: Interactive capacity, mass, and time measurements.
  - *Life Science*: Visualizing biological life cycles.
  - *Physical Science*: Observing forces and circuits.
  - *Number Concepts*: Grasping abstract symbols like fractions and place values.
- **Shared AR Framework**: Built using **Unity 3D** and **Vuforia** for robust marker recognition on standard Android 8.0+ devices without needing specialized headsets.
- **Bilingual Interface**: Seamless toggling between Sinhala and English labels, instructions, and audio narrations.
- **Fully Offline**: Operates fully on-device after installation, accommodating areas with low connectivity (optional Firebase sync for anonymized usage logs).
- **Research-Backed**: Evaluated in real classrooms via quasi-experimental studies to prove large, consistent learning gains.

## 🎨 Design System & Colors

The website features a modern, clean, and highly professional design aesthetic. It prioritizes readability and uses vibrant color accents to highlight the different research components, while preserving a pure white background for an academic, document-like feel.

- **Primary Background (`#ffffff`)**: Pure white backgrounds provide a crisp layout, perfect for showcasing research data clearly.
- **Foreground Text**: Deep, high-contrast Slate grays (`#0f172a`) in light mode and off-whites (`#e8eef8`) in dark mode.
- **Component Colors**: Each of the 4 research components uses a distinct, vibrant accent color that tints its respective cards, badges, and interface elements:
  - **Measurement**: Bright Blue (`#2563eb`) with a soft blue background tint (`#eff6ff`)
  - **Life Science**: Emerald Green (`#059669`) with a soft green background tint (`#ecfdf5`)
  - **Physical Science**: Amber Orange (`#ea580c`) with a soft amber background tint (`#fff7ed`)
  - **Number Concepts**: Violet (`#7c3aed`) with a soft violet background tint (`#f5f3ff`)
- **Vibrant Accents**: Important call-to-action buttons and main titles utilize a rich blue-to-teal linear gradient to draw focus without overwhelming the layout.
- **Ambient Glows**: The hero sections feature large, heavily blurred, colorful orbs representing the 4 components, creating a subtle atmospheric glow over the white background.
- **Clean Interactions**: Elements hover and transition smoothly with soft drop shadows, providing a tactile and premium presentation.
- **Dark Mode Support**: Full class-based (`.dark`) dark mode with rich, deeply saturated backgrounds (e.g., `#0b1220`) for a modern, eye-friendly alternative.

## 🛠️ Tech Stack

- **Framework**: Vite + React
- **Routing**: TanStack Router (`@tanstack/react-router`)
- **Styling**: Tailwind CSS (v4) with centralized CSS variables for theming
- **Icons**: Lucide React
